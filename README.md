# ToDo_app

シンプルな個人用 ToDo（タスク）管理アプリ。
Flask と SQLite を使って実装。

## 機能一覧

- ユーザー管理
  - ユーザー名とパスワードによるログイン
  - 存在しないユーザーでログインすると自動的に新規登録される（簡易登録）
  - ログアウト機能
- タスク管理
  - タスクの作成（タイトルのみ）
  - タスクの完了/未完了の切替
  - タスクの削除
  - タスクはユーザーごとに分離され、ログインしたユーザーのタスクのみ表示
- UI/UX
  - シンプルな HTML テンプレート（`templates/index.html`, `templates/login.html`）
  - フラッシュメッセージによる簡易フィードバック

## ファイル構成

- `app.py` - Flask アプリのエントリポイント。ルーティングと画面ロジック。
- `db_manager.py` - SQLite を操作する `DatabaseManager` クラス。ユーザーとタスクの CRUD を提供。
- `task.py` - `Task` クラス（タスクモデル）。
- `user.py` - `User` クラス（ユーザーモデル）。
- `templates/` - HTML テンプレート (`index.html`, `login.html`)。
- `static/css/` - スタイルシート

## 動作環境

- Python 3.8 以上（実行環境に応じて）
- 依存パッケージ: Flask
- データベース: SQLite（`tasks.db` がルートに作成されます）

必要なパッケージは次のようにインストールできます:

```bash
pip install Flask
```

## 使い方（簡易）

1. リポジトリのルートで依存関係をインストールします。
2. `app.py` を実行します:

```bash
python app.py
```

3. ブラウザで `http://127.0.0.1:5000/login` にアクセスします。
4. ユーザー名とパスワードを入力してログインします。存在しないユーザー名を入力すると新規登録されます。
5. タスクを追加、完了切替、削除できます。

## 注意点 / 今後の改善案

- パスワードはプレーンテキストで保存されています。実運用ではハッシュ化（bcrypt など）を必須にしてください。
- CSRF 保護がありません。Flask-WTF 等の導入を検討してください。
- 入力バリデーションやエラーハンドリングを強化すると安全性が向上します。
- テスト（ユニット／統合）を追加してください。
